# CreatorOps Operating Guide

A practical step-by-step guide for setting up artists, campaigns, assets, products, analytics, AI agents, and weekly operating rhythms.

**In-app route:** `/operating-guide`

---

## Core message

**You do not need to fill every module before using CreatorOps.** Start with one artist, one release, one Drive folder, one campaign, and one learning loop.

---

## 1. Start Here

### What CreatorOps is

A local-first operating system for AI music artists — identity, releases, YouTube, products, analytics, and reusable learnings in one workspace.

### What to set up first

1. Artist Bible + Visual Identity (who the artist is and how they look)
2. A few Lore entries and Song Concepts (creative raw material)
3. One Google Drive folder synced and linked as assets
4. One release campaign with YouTube packaging
5. One learning after your first publish or review

### What not to worry about yet

- Perfect data in every module
- Full revenue tracking before first product
- Every automation rule or pattern
- Connecting every historical video on day one

### Recommended first 7 days

| Days | Focus |
|------|--------|
| 1–2 | Artist Universe (Bible, Visual, Lore, Songs) |
| 3 | Drive folder + asset linking |
| 4 | First campaign + YouTube package |
| 5 | Publish or import video, run Campaign QA |
| 6 | One product research idea or mockup |
| 7 | Weekly review — learnings, patterns, one playbook tweak |

### Minimum usable setup checklist

- [ ] Create or review Artist Bible → `/artist-bible`
- [ ] Create Visual Identity → `/visual-identity`
- [ ] Add 3–5 Lore entries → `/lore`
- [ ] Add 3–5 Song Concepts → `/song-vault`

- [ ] Import/sync YouTube videos → `/integrations?tab=youtube-api`
- [ ] Run Campaign QA Agent → `/agents?tab=run&agentId=campaign-qa`
- [ ] Create first Learning → `/learnings`

## 3. Artist Universe

Artist Universe keeps songs, visuals, lore, and AI prompts aligned for one IP.

| Module | Purpose | Start with | Good enough |
|--------|---------|------------|-------------|
| **Artist Bible** | Central identity: voice, genre, mood, rules | Name, genre, mood, visual rules | One bible with genre, mood, 3+ do/don't bullets |
| **Lore Manager** | Worldbuilding, symbols, characters | 3 entries: world, symbol, character | Canon status on 1–2 core pieces |
| **Song Concept Vault** | Hooks, prompts, visuals before production | Title, summary, hook, visual | 3 concepts with summary + hook |
| **Release Story Arcs** | Connect songs and campaigns across an era | Title, theme, 3 beats | Arc linked to 2+ songs or one campaign |
| **Visual Identity** | Thumbnail, merch, image prompt rules | Profile name, colors, thumbnail rules | Active profile with palette + rules |

### Minimum viable artist universe

- [ ] One Artist Bible
- [ ] One Visual Identity Profile
- [ ] Three Lore Entries
- [ ] Three Song Concepts
- [ ] One Story Arc
- [ ] One Drive reference folder

## 9. AI Agents

| Agent | When to run | Context | Use result to |
|-------|-------------|---------|---------------|
| **Release Strategist** | Before/during release planning | Bible, lore, songs, campaigns | Prioritize launch tasks |
| **YouTube Growth Strategist** | After video sync | Videos, analytics, packaging | Packaging and growth ideas |
| **Product Strategist** | Merch/collection planning | Research, listings, collections | Product opportunities |
| **Prompt Optimizer** | Prompts underperform | Prompt library, recent runs | Sharper templates |
| **Campaign QA** | Before publish | Campaign links, assets | Gap list before launch |
| **Learning Synthesizer** | After weekly review | Learnings, experiments, analytics | Consolidated insights |

### Recommended usage

- **Before launch:** Campaign QA + Release Strategist
- **After video sync:** YouTube Growth Strategist
- **During product planning:** Product Strategist
- **After weekly review:** Learning Synthesizer
- **When prompts perform poorly:** Prompt Optimizer

## 10. Troubleshooting

| Problem | What to try |
|---------|-------------|
| No data showing | Check SQLite (`DATABASE_URL`). Run `npx prisma migrate deploy`. Create records in the right module. |
| Videos not syncing | Reconnect YouTube API under Integrations. Confirm OAuth and channel. |
| Drive folder not syncing | Reconnect Google Drive. Pick folder in Integrations. Check Data Health. |
| Empty tabs | Normal with no records — use empty states. Refresh if tabs are blank with no message. |
| Missing assets | Data Health → Missing Assets. Link Drive files or create from campaigns. |
| AI provider not configured | Settings → AI provider. Add API key server-side. |

### Useful commands

```bash
npx prisma validate
npx prisma generate
npx prisma migrate status
npm run build
npm run dev
```
